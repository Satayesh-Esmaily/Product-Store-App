# Product Store App

A modular React application built as part of a Week 7–9 assignment.  
The project focuses on demonstrating modern React state management and data fetching patterns using React Query, Redux Toolkit, and Context API.

---

## Overview

This application allows users to browse products, view product details, and manage a shopping cart.  
Different state management approaches are used based on the type of state:

- React Query for server state (API data)
- Redux Toolkit for global application state (cart)
- Context API with useReducer for UI settings

---

## Features

- Product listing from a public API
- Reusable product components
- Shopping cart with add/remove functionality
- Global state management with Redux Toolkit
- Settings management using Context API + useReducer
- Loading state handling for asynchronous requests

---

## Tech Stack

- React

- Redux Toolkit
